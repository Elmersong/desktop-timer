# desktop-timer / 桌面计时器

desktop-timer is a lightweight desktop timer designed for focus sessions and simple time awareness on Windows.

desktop-timer 是一个轻量的桌面计时工具，面向 Windows 场景下的专注工作与基础时间管理。

---

## Overview / 项目简介

desktop-timer is built for users who want a timer that stays close to the task itself.

Instead of opening a complex productivity system, users can directly start a simple timer on the desktop and keep track of time in a more natural way.

desktop-timer 面向这样一类用户：他们希望计时工具尽可能贴近任务本身，而不是让自己进入一个复杂的效率系统。

用户可以直接在桌面上启动一个简单计时器，更自然地感知时间流逝，并保持当前任务的专注状态。

---

## Core Idea / 核心思路

The core idea of desktop-timer is simple:
- keep the timer visible
- reduce interaction cost
- support focused work with minimal friction

It is not designed to be a heavy productivity platform.  
Instead, it focuses on doing one small thing well: making time visible during focused work.

desktop-timer 的核心思路很简单：
- 让计时器保持可见
- 降低交互成本
- 用尽可能小的阻力支持专注工作

它并不是一个功能繁重的效率平台。  
相反，它聚焦于把一件小事做好：在专注过程中，让时间变得可见。

---

## What Problem It Solves / 它解决什么问题

In many work or study situations, users do not need a complicated system.  
They only need:
- a timer that is easy to start
- a timer that is visible during work
- a timer that does not interrupt the task itself

desktop-timer is designed around this small but frequent need.

在很多工作和学习场景里，用户并不需要一个复杂系统。  
他们真正需要的往往只是：
- 一个容易启动的计时器
- 一个在工作过程中看得见的计时器
- 一个不会反过来打扰任务本身的计时器

desktop-timer 就是围绕这个高频但细小的需求来设计的。
